# Media

Drop screenshots and gameplay video here, then link them from the main `README.md`.

## What's worth showing

Pick shots that make the *systems* visible, not just pretty scenery:

1. **Night gameplay with the flashlight** — the hard-edged beam and darkness sell the horror.
2. **A monster mid-chase** — proof the AI works.
3. **The co-op lobby or two players with nameplates** — proof the networking works.
4. **The inventory / crafting bench open** — proof of the UI and crafting systems.
5. **The river, ritual altar, or radio tower** — the set-piece locations.
6. **A short gameplay clip** (30–60 s) — day prep cutting to a night raid.

## Keeping it reviewer-friendly

- GitHub rejects any single file over **100 MB**. Keep clips well under that — 20–30 MB is plenty
  for a compressed 1080p minute.
- If a video is large, upload it to YouTube (unlisted) or Drive and link it from the README instead.
  A reviewer is more likely to click a link than wait for a download.
- PNG for UI screenshots, JPG for scenery — smaller files, faster page load.

## Linking from the main README

Add a section near the top of `../README.md`:

```markdown
## Screenshots

![Night raid](media/night-raid.png)
![The stalker](media/monster-chase.png)
![Co-op lobby](media/lobby.png)

```
